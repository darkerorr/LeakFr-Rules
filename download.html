01 / INSTALLATION

Choisis ton environnement.

Les commandes ci-dessous installent le projet depuis son dépôt GitHub. Chaque bloc est copiable.

01 / DESKTOP

Windows · PowerShell

Windows 10/11

Installe Python 3.9 ou supérieur et Git avant de commencer.

COMMANDES 
git clone https://github.com/darkerorr/LeakFr-Tools.git
cd LeakFr-Tools
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py

Si PowerShell bloque l'activation de l'environnement, exécute cette commande dans la fenêtre courante, puis recommence l'activation : 

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
02 / DESKTOP

Linux · Debian / Ubuntu

Linux
COMMANDES 
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip
git clone https://github.com/darkerorr/LeakFr-Tools.git
cd LeakFr-Tools
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
